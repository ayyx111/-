# 校园版咸鱼 — 项目部署说明文档

> 项目名称:校园版咸鱼(校园二手交易平台)
> 文档版本:V1.0
> 编写日期:2026-08-16
> 适用环境:Windows / macOS / Linux

---

## 一、环境要求

### 1.1 必需环境

| 软件 | 最低版本 | 说明 |
|------|----------|------|
| Node.js | 18.0+ | 后端运行环境(建议 20 LTS) |
| Python | 3.10+ | AI 服务运行环境 |
| npm | 9.0+ | 随 Node.js 安装 |
| pip | 23.0+ | Python 包管理 |

### 1.2 无需外部依赖

本项目使用 SQLite(文件数据库)和 Node-Cache(内存缓存),**无需安装 MySQL、Redis 等外部服务**,开箱即用。

### 1.3 可选环境(生产部署)

| 软件 | 说明 |
|------|------|
| Docker + Docker Compose | 容器化部署(可选) |
| Nginx | 反向代理、HTTPS、静态资源(可选) |
| IGA Pages CLI | 前端静态部署到火山引擎(可选) |

## 三、本地开发部署(零依赖)

### 3.1 后端部署

```bash
# 1. 进入后端目录
cd backend

# 2. 安装依赖
npm install

# 3. 配置环境变量(已默认配置,无需修改)
# .env 文件关键配置:
#   PORT=3000
#   DB_TYPE=sqlite
#   DB_STORAGE=./database.sqlite
#   DB_SYNC=true
#   JWT_SECRET=campus-fish-secret-key
#   AI_SERVICE_URL=http://localhost:8000

# 4. 创建上传目录
mkdir uploads

# 5. 启动服务
node src/app.js
```

启动成功标志:
```
[Server] 服务已启动: http://localhost:3000
[Server] API 基础路径: /api/v1
[Server] WebSocket: ws://localhost:3000/ws/chat
```

验证: 访问 http://localhost:3000/health 返回 `{"code":200,...}`

### 3.2 AI 服务部署

```bash
# 1. 进入 AI 服务目录
cd ai-service

# 2. 创建虚拟环境(推荐)
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

启动成功标志:
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

验证: 访问 http://localhost:8000/health 返回 `{"status":"ok"}`

### 3.3 前端部署

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

启动成功标志:
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

验证: 浏览器访问 http://localhost:5173

## 四、生产环境部署

### 4.1 前端构建

```bash
cd frontend

# 配置生产环境 API 地址
# 编辑 .env.production:
#   VITE_API_BASE_URL = http://你的服务器IP:3000/api/v1
#   VITE_WS_URL = ws://你的服务器IP:3000

# 构建静态文件
npm run build
# 产物输出到 dist/ 目录
```

### 4.2 方式一:IGA Pages 部署(推荐)

```bash
# 1. 安装 CLI
npm i -g @iga-pages/cli@latest

# 2. 登录(浏览器授权)
iga login

# 3. 部署
cd frontend
iga pages deploy --name campus-flea
```

部署完成后获得公网访问链接。

### 4.3 方式二:Nginx 部署

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # WebSocket 代理
    location /ws/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### 4.4 后端生产部署

```bash
# 使用 PM2 进程管理(推荐)
npm install -g pm2

cd backend
pm2 start src/app.js --name campus-fish-backend
pm2 save
pm2 startup  # 开机自启
```

### 4.5 AI 服务生产部署

```bash
cd ai-service

# 使用 nohup 后台运行
nohup uvicorn app.main:app --host 0.0.0.0 --port 8000 > ai-service.log 2>&1 &

# 或使用 gunicorn(需安装)
pip install gunicorn
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

## 五、Docker Compose 部署(可选)

### 5.1 docker-compose.yml

```yaml
version: '3.8'

services:
  frontend:
    build: ./frontend
    ports:
      - "80:80"
    depends_on:
      - backend

  backend:
    build: ./backend
    ports:
      - "3000:3000"
    volumes:
      - ./data/db:/app/backend/database.sqlite
      - ./data/uploads:/app/backend/uploads
    environment:
      - NODE_ENV=production
      - DB_TYPE=sqlite

  ai-service:
    build: ./ai-service
    ports:
      - "8000:8000"
```

### 5.2 启动

```bash
docker-compose up -d
```

## 八、局域网访问配置

### 8.1 前端配置

`frontend/vite.config.js` 中配置 `host: '0.0.0.0'`:

```javascript
server: {
  host: '0.0.0.0',  // 允许局域网访问
  port: 5173,
}
```

### 8.2 防火墙规则(Windows)

```powershell
# 开放端口
New-NetFirewallRule -DisplayName "CampusFish-Frontend-5173" -Direction Inbound -Protocol TCP -LocalPort 5173 -Action Allow
New-NetFirewallRule -DisplayName "CampusFish-Backend-3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
New-NetFirewallRule -DisplayName "CampusFish-AI-8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

### 8.3 局域网访问地址

获取本机 IP 后,其他电脑访问:
```
http://你的IP:5173
```

## 九、常见问题

### Q1: 后端启动报 "Cannot find module 'xxx'"

```bash
cd backend && npm install
```

### Q2: 前端 API 请求 404

检查 `frontend/.env.production` 中的 `VITE_API_BASE_URL` 是否指向正确的后端地址。

### Q3: AI 服务启动报 "ModuleNotFoundError"

```bash
cd ai-service
pip install -r requirements.txt
```

### Q4: 图片上传失败

确保 `backend/uploads/` 目录存在且有写入权限。

### Q5: SQLite 数据库重置

删除 `backend/database.sqlite` 文件,重启后端服务会自动重建。

### Q6: 切换到 MySQL(可选)

修改 `backend/.env`:
```
DB_TYPE=mysql
DB_HOST=localhost
DB_PORT=3306
DB_NAME=campus_fish
DB_USER=root
DB_PASSWORD=your_password
```

## 十、一键启动脚本(Windows)

```powershell
# start-all.ps1
# 启动后端
Start-Process -NoNewWindow -FilePath "node" -ArgumentList "src/app.js" -WorkingDirectory "backend"

# 启动 AI 服务
Start-Process -NoNewWindow -FilePath "python" -ArgumentList "-m uvicorn app.main:app --port 8000" -WorkingDirectory "ai-service"

# 启动前端
Start-Process -NoNewWindow -FilePath "npm" -ArgumentList "run dev" -WorkingDirectory "frontend"

Write-Host "所有服务已启动:"
Write-Host "  前端: http://localhost:5173"
Write-Host "  后端: http://localhost:3000"
Write-Host "  AI服务: http://localhost:8000"
```
