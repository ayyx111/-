## 一、测试概述

### 1.1 测试目标

验证校园版咸鱼平台各功能模块的正确性、安全性和性能,确保系统满足功能规格说明书中的需求。

### 1.2 测试范围

| 测试类型 | 范围 |
|----------|------|
| 单元测试 | 后端服务层/控制器层、前端组件 |
| 接口测试 | 全部49个API接口 |
| 功能测试 | 用户/商品/交易/消息/AI/管理6大模块 |
| 安全测试 | 认证/权限/SQL注入/XSS/文件上传 |
| 性能测试 | API响应时间、并发承载 |
| 兼容性测试 | 浏览器兼容、响应式适配 |
