## 一、项目概述

### 1.1 项目背景

大学生在校期间有大量闲置物品(教材、数码、生活用品等),传统转让方式信息不对称、效率低。校园版咸鱼是一个面向高校学生的二手物品交易平台,提供安全、便捷的校内交易环境。

### 1.2 项目目标

| 目标 | 描述 |
|------|------|
| 核心目标 | 为在校大学生提供安全便捷的校园二手交易服务 |
| 用户目标 | 快速发布、搜索、买卖闲置物品 |
| 业务目标 | 校园身份认证保障交易安全,AI 提升交易效率 |
| 技术目标 | 全栈开发,前后端分离,AI 智能赋能 |

### 1.3 目标用户

| 用户角色 | 描述 | 占比预估 |
|----------|------|----------|
| 买家 | 浏览、搜索、购买二手商品的学生 | 70% |
| 卖家 | 发布、管理闲置商品的学生 | 60% |
| 管理员 | 审核商品、管理用户、处理纠纷 | 1% |

> 注:买家与卖家角色可互换,同一用户既可买也可卖。

## 六、业务规则汇总

| 编号 | 规则描述 |
|------|----------|
| BR-01 | 用户必须完成校园认证才能发布商品和购买 |
| BR-02 | 不可购买自己发布的商品 |
| BR-03 | 商品发布需经审核(AI+人工)通过后上架 |
| BR-04 | 订单创建后商品锁定,不可被其他人下单 |
| BR-05 | 订单待确认状态下卖家可拒绝,商品恢复在售 |
| BR-06 | 交易完成后双方互评,评价不可修改 |
| BR-07 | 连续5次密码错误锁定账号30分钟 |
| BR-08 | 违规用户被封禁后无法登录和交易 |
| BR-09 | 下架商品可重新上架,已售商品不可编辑 |
| BR-10 | 商品售价必须大于0,不超过99999元 |

## 八、验收标准

1. 用户可完成注册、登录、校园认证全流程
2. 用户可发布商品并经审核上架
3. 用户可搜索、浏览、查看商品详情
4. 买家可下单,卖家可确认,双方可完成交易

6. 系统可根据用户行为推荐商品
7. 管理员可审核商品、管理用户
8. 系统可正常部署并远程访问
9. 核心接口响应时间满足性能要求
