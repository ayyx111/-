# 校园版咸鱼 — 原型设计文档(页面布局)

> 项目名称:校园版咸鱼(校园二手交易平台)
> 文档类型:原型设计文档 (Prototype Design)
> 文档版本:V1.0
> 编写日期:2026-08-16

---

## 一、设计说明

- 设计风格:简洁清新,校园主题(主色 #4CAF50 绿色,辅色 #FF9800 橙色)
- 响应式:PC端宽屏布局 + 移动端适配
- 导航模式:顶部导航栏(PC) + 底部标签栏(移动端)
- 组件库:Element Plus

---

## 二、页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | / | 商品列表、分类、推荐 |

| 注册 | /register | 用户注册 |

| 聊天 | /messages/:userId | 即时聊天 |
| 个人中心 | /profile | 个人资料 |
| 我的发布 | /profile/products | 我发布的商品 |
| 我的订单 | /profile/orders | 买卖订单 |
| 我的收藏 | /profile/favorites | 收藏列表 |

| 管理后台 | /admin | 管理员功能 |
| 智能客服 | /chatbot | AI客服 |

## 四、交互设计要点

| 场景 | 交互方式 |
|------|----------|
| 商品列表滚动 | 无限滚动加载 / 分页加载 |
| 图片预览 | 点击放大,支持左右滑动 |
| 搜索 | 输入时联想,回车搜索,空结果推荐 |
| 下单确认 | 弹窗确认,显示商品信息 |
| 消息推送 | 浏览器通知 + 红点提示 |
| 表单校验 | 实时校验,错误提示 |
| 加载状态 | 骨架屏 / Loading动画 |
| 操作反馈 | Toast提示成功/失败 |
